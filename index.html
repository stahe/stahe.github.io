    Cours de programmation – Programming Courses

    Serge Tahé - About the author

    Ce site propose des cours de programmation gratuits, en français et en anglais. Chaque cours avance pas à pas : de nombreux petits exemples commentés, chacun centré sur une seule notion, le plus souvent suivis d’une étude de cas complète. Le PDF et les codes de chaque cours sont téléchargeables.

    This site offers free programming courses, in French and in English. Each course proceeds step by step: many small commented examples, each focused on a single concept, most often followed by a complete case study. The PDF and the code of each course can be downloaded.

    Français

    Les cours ci-dessous ont été écrits en septembre et octobre 2026 par l’IA Claude d’Anthropic, à la demande de Serge Tahé.

    Frameworks web côté serveur

    Dans ces sept cours, les pages HTML sont fabriquées par le serveur. Ils traitent les mêmes 28 exemples, numéro par numéro, puis la même étude de cas, RdvMedecins, une application de prise de rendez-vous médicaux : on peut ainsi comparer les frameworks.

    • [Introduction étape par étape au framework web [NestJS] (sept 2026)] : une application web MVC en TypeScript, avec des vues Handlebars, TypeORM et MySQL ;
    • [Introduction étape par étape au framework web [ASP.NET Core MVC] (sept 2026)] : une application web MVC en C# avec .NET 10, des vues Razor et Entity Framework Core ;
    • [Introduction étape par étape au framework web [Spring MVC] (sept 2026)] : une application web en Java 21 avec Spring Boot 4, des vues Thymeleaf, Spring Security et Hibernate ;
    • [Introduction étape par étape au framework web [Flask] (sept 2026)] : une application web MVC en Python avec Flask 3.1, des vues Jinja2, Pydantic, WTForms et SQLAlchemy ;
    • [Introduction étape par étape au framework web [Laravel] (sept 2026)] : une application web MVC en PHP 8.4 avec Laravel 13, des vues Blade et l’ORM Eloquent ;
    • [Introduction étape par étape au framework web [Symfony] (sept 2026)] : une application web MVC en PHP 8.4 avec Symfony 8.1, des vues Twig et l’ORM Doctrine ;
    • [Introduction étape par étape au framework web [Django] (sept 2026)] : une application web MVC en Python avec Django 6.1, ses gabarits et son ORM.

    Frameworks côté client

    Dans ces quatre cours, les pages sont fabriquées dans le navigateur, ou sur le téléphone, à partir des données JSON d’un serveur. Chacun écrit le client de la même application RdvMedecins, d’abord à travers de petits exemples, puis dans une étude de cas complète.

    • [Introduction étape par étape au framework web [Vue.js] (sept 2026)] : une application à page unique avec Vue.js 3, vue-router, Pinia et vue-i18n ;
    • [Introduction étape par étape au framework web [Angular] (sept 2026)] : une application à page unique avec Angular 22, ses signaux, son routeur et RxJS ;
    • [Introduction étape par étape au framework web [React] (sept 2026)] : une application à page unique avec React 19, React Router, Zustand et TanStack Query ;
    • [Introduction étape par étape au framework mobile [Flutter] (sept 2026)] : une application mobile Android, qui tourne aussi dans un navigateur, avec Flutter et Dart.

    Exemples client / serveur complets

    Ces quatre cours construisent l’application RdvMedecins de bout en bout : un serveur NestJS qui expose une API JSON, une base MySQL et un client.

    • [Un exemple de client / serveur Angular / NestJS (sept 2026)] : le serveur NestJS (TypeORM, MySQL, jetons JWT) et son client Angular 22 ;
    • [Un exemple de client / serveur React / NestJS (sept 2026)] : le serveur NestJS et son client React 19, écrit avec Vite et TypeScript ;
    • [Un exemple de client / serveur Vue.js / NestJS (sept 2026)] : le serveur NestJS et son client Vue.js 3, écrit avec la Composition API ;
    • [Une application client / serveur [Flutter] / [NestJS] (sept 2026)] : un client mobile Flutter pour le serveur NestJS, porté ensuite vers le bureau et le web.

    Langages

    Ces trois cours enseignent un langage à travers de petits scripts commentés ligne par ligne.

    • [Introduction au langage TypeScript et au framework web NestJS par l’exemple (sept 2026)] : le langage TypeScript depuis ses fondamentaux, l’accès aux bases de données (mysql2, TypeORM, Prisma), puis le framework NestJS ;
    • [Introduction au langage Dart par l’exemple (sept 2026)] : le langage Dart, ses fonctions HTTP et l’accès à une base MySQL ;
    • [Introduction au langage PHP 8 par l’exemple (oct 2026)] : le langage PHP 8.5, sans aucune fonctionnalité dépréciée : classes, exceptions, tests PHPUnit, bases MySQL et PostgreSQL, réseau, services web, jusqu’à une application web MVC (fil rouge : un calcul d’impôt en 13 versions).

    Les cours plus anciens (Java, .NET, JavaScript, PHP, Python, SQL), écrits par Serge Tahé entre 1998 et 2020, sont sur une page séparée : Autres cours disponibles (1998-2020).

    English

    The courses below were written in September and October 2026 by Anthropic’s AI Claude, at the request of Serge Tahé. The English versions of the September 2026 courses were translated with DeepL; from October 2026 onwards, they are translated by Claude itself.

    Server-side web frameworks

    In these seven courses, the HTML pages are generated by the server. They cover the same 28 examples, number by number, then the same case study, RdvMedecins, a medical appointment-booking application, so the frameworks can be compared.

    • [Step-by-Step Introduction to the [NestJS] Web Framework (sept 2026)] : an MVC web application in TypeScript, with Handlebars views, TypeORM and MySQL;
    • [Step-by-Step Introduction to the [ASP.NET Core MVC] Web Framework (sept 2026)] : an MVC web application in C# with .NET 10, Razor views and Entity Framework Core;
    • [Step-by-Step Introduction to the [Spring MVC] Web Framework (sept 2026)] : a web application in Java 21 with Spring Boot 4, Thymeleaf views, Spring Security and Hibernate;
    • [Step-by-Step Introduction to the [Flask] Web Framework (sept 2026)] : an MVC web application in Python with Flask 3.1, Jinja2 views, Pydantic, WTForms and SQLAlchemy;
    • [Step-by-Step Introduction to the [Laravel] Web Framework (sept 2026)] : an MVC web application in PHP 8.4 with Laravel 13, Blade views and the Eloquent ORM;
    • [Step-by-Step Introduction to the [Symfony] Web Framework (sept 2026)] : an MVC web application in PHP 8.4 with Symfony 8.1, Twig views and the Doctrine ORM;
    • [Step-by-Step Introduction to the [Django] Web Framework (sept 2026)] : an MVC web application in Python with Django 6.1, its templates and its ORM.

    Client-side frameworks

    In these four courses, the pages are built in the browser, or on the phone, from the JSON data of a server. Each one writes the client of the same RdvMedecins application, first through small examples, then in a complete case study.

    • [Step-by-Step Introduction to the [Vue.js] Web Framework (sept 2026)] : a single-page application with Vue.js 3, vue-router, Pinia and vue-i18n;
    • [Step-by-Step Introduction to the [Angular] Web Framework (sept 2026)] : a single-page application with Angular 22, its signals, its router and RxJS;
    • [Step-by-Step Introduction to the [React] Web Framework (sept 2026)] : a single-page application with React 19, React Router, Zustand and TanStack Query;
    • [Step-by-Step Introduction to the [Flutter] Mobile Framework (sept 2026)] : an Android mobile application, which also runs in a browser, with Flutter and Dart.

    Complete client/server examples

    These four courses build the RdvMedecins application from end to end: a NestJS server that exposes a JSON API, a MySQL database and a client.

    • [An Angular/NestJS Client/Server Example (sept 2026)] : the NestJS server (TypeORM, MySQL, JWT) and its Angular 22 client;
    • [A React/NestJS Client/Server Example (sept 2026)] : the NestJS server and its React 19 client, written with Vite and TypeScript;
    • [A Vue.js/NestJS Client/Server Example (sept 2026)] : the NestJS server and its Vue.js 3 client, written with the Composition API;
    • [A [Flutter] / [NestJS] client/server application (sept 2026)] : a Flutter mobile client for the NestJS server, then ported to desktop and web.

    Languages

    These three courses teach a language through small scripts commented line by line.

    • [Introduction to the TypeScript language and the NestJS web framework through examples (sept 2026)] : the TypeScript language from its fundamentals, database access (mysql2, TypeORM, Prisma), then the NestJS framework;
    • [Introduction to the Dart Language Through Examples (sept 2026)] : the Dart language, its HTTP functions and access to a MySQL database;
    • [Introduction to the PHP 8 Language by Example (oct 2026)] : the PHP 8.5 language, without any deprecated feature: classes, exceptions, PHPUnit tests, MySQL and PostgreSQL databases, networking, web services, up to an MVC web application (common thread: a tax calculation in 13 versions).

    The older courses (Java, .NET, JavaScript, PHP, Python, SQL), written by Serge Tahé between 1998 and 2020, are on a separate page: Other available courses (1998-2020).
